# Security Policy

## Reporting a vulnerability
Please do not open a public issue for security vulnerabilities. Contact the repository owner privately through GitHub to report:
- exposed credentials
- uploaded-image access problems
- user-profile data leaks
- authentication bypasses
- unsafe file-upload behavior
- cross-site scripting issues
- insecure API endpoints

## Sensitive data
Never commit:
- .env files
- API tokens
- Supabase service-role keys
- production database credentials
- uploaded food-label images
- user health profile data
- production logs
