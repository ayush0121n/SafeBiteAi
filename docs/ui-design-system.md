# SafeBite AI UI System

## Design principles
- Calm and friendly healthcare visual language
- Large readable text
- Minimal visual clutter
- One primary action per screen
- High contrast by default
- Icons always accompanied by text
- Clear uncertainty labels

## Colors
Background: #F7F8F3
Surface: #FFFFFF
Primary: #4E8F68
Text: #19352A
Muted text: #6D7B73
Safe: #4E9B69
Caution: #E7A63F
Avoid: #D95D59
Uncertain: #687C8C

## Typography
- Font: DM Sans or Nunito Sans
- Body minimum: 18px
- Main buttons: minimum 18px
- Touch targets: minimum 48px
- Use a maximum of three font weights

## Status labels
- Safe: Looks suitable based on the readable label
- Caution: Review before eating
- Avoid: Contains something in your avoid list
- Uncertain: We could not read enough of the label
