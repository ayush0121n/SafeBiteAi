# Accessibility Checklist

- [ ] Body text is at least 18px
- [ ] All primary controls are at least 48px tall
- [ ] Status uses icon + text + colour
- [ ] Keyboard navigation works across every page
- [ ] Focus outline is visible
- [ ] Upload errors are announced to screen readers
- [ ] Processing state is announced to screen readers
- [ ] Large-text mode works without layout overflow
- [ ] High-contrast mode meets readable contrast requirements
- [ ] Voice readout is optional
- [ ] Results use plain, non-medical language
- [ ] Uncertainty is visible and understandable
