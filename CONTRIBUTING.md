# Contributing to SafeBite AI

Thank you for contributing.

## Before opening a pull request
- Create a focused branch.
- Do not commit .env files, API keys, uploaded images, or user data.
- Run frontend linting, type checks, tests, and production build.
- Run backend tests.
- Add tests for changed allergen, nutrition, or concern rules.
- Update documentation if API behavior changes.
- Keep health guidance non-diagnostic and plain-language.

## Commit format
Use conventional commits:
- feat: add upload preview
- fix: improve peanut alias matching
- docs: update installation steps
- test: add sodium concern test
- chore: update dependencies
